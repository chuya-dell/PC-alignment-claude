# 基板位置合わせスクリプト 要件定義書

## 1. 概要

顕微鏡等で撮影した基板（サンプル）のグレースケールTIFF画像群を、1枚の基準画像に対して
**回転補正**と**平行移動補正**を行い、位置を揃えた画像として出力するスクリプトの要件を定義する。

補正の手がかりとして、基板上に存在する **直線状のスクラッチ（傷）** を利用する。
スクラッチは周囲より暗い（輝度が低い）線として写っており、以下の2種類を検出対象とする。

- **縦線（ほぼ垂直な線）**: 傾きの検出に使用し、回転補正に用いる
- **横線（ほぼ水平な線）**: 位置（行）の検出に使用し、平行移動補正に用いる

縦線は、位置（列）の検出にも使用する。

## 2. 目的

- 撮影ごとに生じるサンプルの微小な回転・並進ズレを補正し、複数画像間で同一箇所を
  ピクセル単位で比較できるようにする。
- 補正処理を自動化し、人手による位置合わせを不要にする。

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| 基準画像（REFERENCE） | 位置合わせの基準となる1枚の画像 |
| 対象画像（TARGET） | 基準画像に合わせて補正される画像（複数可） |
| 縦線 | 基板上のほぼ垂直なスクラッチ。暗い画素として写る |
| 横線 | 基板上のほぼ水平なスクラッチ。暗い画素として写る |
| 縦線角度 | 縦線の、垂直方向からの傾き（度） |
| 縦線col | 縦線の水平方向の位置（列インデックス） |
| 横線row | 横線の垂直方向の位置（行インデックス） |

## 4. 前提条件・制約

- 入力画像はグレースケール、TIFF形式（16bit / float等、輝度値として扱えるもの）。
- 想定画像サイズは 2048×2048 px 程度（座標範囲のデフォルト値がこのサイズを前提としている）。
- 各画像には、指定した探索範囲内に検出可能な暗い縦線・横線が1本ずつ存在する。
- 基準画像・対象画像は同一の座標系（同一撮影条件・同一画角）で撮影されている前提とする
  （検出範囲のズレが極端に大きい場合は対象外）。
- 出力画像は最終的に輝度値を 0–255 にクリップし、8bit（uint8）で保存する。

## 5. 入出力仕様

### 5.1 入力

| 項目 | 内容 |
|---|---|
| 入力ディレクトリ | 位置合わせ対象の画像群が格納されたフォルダ |
| 基準画像ファイル名 | 入力ディレクトリ内の1ファイル（例: `1-0.tif`） |
| 対象画像ファイル名リスト | 入力ディレクトリ内の複数ファイル（例: `1-1.tif`, `1-2.tif`, ...） |

- 対象画像リストの中に存在しないファイルがあった場合はスキップし、処理を継続する（エラー終了しない）。

### 5.2 出力

| 項目 | 内容 |
|---|---|
| 出力ディレクトリ | 入力ディレクトリ配下の `registered` サブフォルダ（存在しなければ作成） |
| 出力ファイル名 | `{元のファイル名（拡張子なし）}_registered.tif` |
| 出力形式 | TIFF、8bit（uint8）、輝度値は 0–255 にクリップ |
| 標準出力ログ | 基準画像の検出結果、各対象画像の補正結果、全体サマリー表（後述） |

## 6. 機能要件

### 6.1 設定項目（パラメータ）

| パラメータ名 | 説明 | 例 |
|---|---|---|
| 入力ディレクトリ | 画像が置かれているフォルダパス | `位置合わせ` フォルダ |
| 出力ディレクトリ | 補正済み画像の保存先（自動生成） | `位置合わせ/registered` |
| 基準画像ファイル名 | 位置合わせの基準とする画像 | `1-0.tif` |
| 対象画像ファイル名リスト | 補正対象の画像群 | `["1-1.tif", "1-2.tif", "1-3.tif"]` |
| 縦線角度検出用の列範囲 | 傾き検出に使う列の探索範囲 (col_start, col_end) | `(30, 250)` |
| 縦線col検出用の列探索範囲 | 縦線の位置（列）を探す範囲 | `(30, 300)` |
| 横線row検出用の行探索範囲 | 横線の位置（行）を探す範囲 | `(1800, 2044)` |
| 横線row検出用の列範囲 | 横線検出時に縦線の影響を避けるための列範囲 | `(200, 2048)` |
| 平行移動補正時の列探索マージン | 回転後の再検出で、元の縦線col位置から前後何pxを探すか | `150` |

これらは実装時に定数として持つ、または設定ファイル/引数として外出しできる形にする
（後者が望ましいが、必須ではない）。

### 6.2 処理フロー全体

```
1. 基準画像を読み込み、縦線角度・縦線col・横線rowを検出する
2. 各対象画像について:
   a. 画像を読み込み、縦線角度・縦線col・横線rowを検出する
   b. Step1: 回転補正
      - 回転角 = 基準の縦線角度 − 対象の縦線角度
      - 画像中心を回転中心として、その角度だけ画像全体を回転する
   c. Step2: 平行移動補正
      - 回転後の画像に対して、縦線col・横線rowを再検出する
        （縦線colの探索範囲は、回転前に検出した対象の縦線col ± マージンpxに限定する）
      - dx = 基準の縦線col − 回転後画像の縦線col
      - dy = 基準の横線row − 回転後画像の横線row
      - (dx, dy) だけ画像全体を平行移動する
   d. 輝度値を0–255にクリップし、8bit化してTIFFとして保存する
   e. 補正結果（回転角、dx, dy, 移動量）をログ出力する
3. 全対象画像の補正結果をまとめたサマリー表を出力する
```

### 6.3 Step1: 回転補正の要件

- **入力**: グレースケール画像（1枚）、縦線角度検出用の列範囲
- **処理**:
  1. 指定した列範囲内において、各行ごとに最も輝度が低い列（＝縦線上の点）を求める。
  2. 行インデックスを説明変数、検出した列インデックスを目的変数として1次の線形回帰
     （最小二乗法）を行い、傾き（slope）を求める。
  3. 傾きから角度（度）を `atan(slope)` により算出する。
- **出力**: 縦線の傾き角度（度、符号付き）
- **回転補正**:
  - 回転角 = 基準画像の縦線角度 − 対象画像の縦線角度
  - 画像中心を回転中心とし、アフィン変換（双線形補間）で画像全体を回転する。
  - 画像外にはみ出す領域は輝度値0（境界定数）で埋める。

### 6.4 Step2: 平行移動補正の要件

- **縦線col検出**:
  - 指定した列探索範囲内で、各列の（全行にわたる）平均輝度を計算し、
    平均輝度が最小となる列を縦線の位置とする。
- **横線row検出**:
  - 指定した行探索範囲・列範囲内で、各行の平均輝度を計算し、
    平均輝度が最小となる行を横線の位置とする。
- **回転後の再検出**:
  - 縦線colの再検出は、回転前に検出した対象画像の縦線col値を中心として
    ±マージン（デフォルト150px）の範囲に限定して行う
    （範囲は画像端を超えないようクリップする）。
  - 横線rowの再検出は、デフォルトの行探索範囲・列範囲をそのまま用いる。
- **平行移動量の算出**:
  - dx = 基準画像の縦線col − 回転後対象画像の縦線col
  - dy = 基準画像の横線row − 回転後対象画像の横線row
  - 上記 (dx, dy) 分だけ画像全体をアフィン変換（双線形補間、はみ出し部分は輝度0）で平行移動する。

### 6.5 ログ出力仕様

**基準画像の検出結果:**
```
基準画像: {ファイル名}
  縦線角度: {角度:.4f}°  縦線col: {col}  横線row: {row}
```

**各対象画像の補正結果:**
```
{ファイル名}:
  縦線角度: {角度:.4f}°  回転補正: {回転角:+.4f}°
  平行移動: dx={dx:+d}px  dy={dy:+d}px  |shift|={移動量:.1f}px
  → 保存: {出力ファイル名}
```

**全体サマリー（表形式）:**
- 列: ファイル名、回転角(deg)、dx(px)、dy(px)、|ズレ|(px)
- 全対象画像分を1行ずつ出力する

**存在しないファイルをスキップした場合:**
```
スキップ: {ファイル名}
```

## 7. 非機能要件

- 画像1枚あたりの処理は独立しており、1枚の失敗が他の画像の処理を止めないこと
  （少なくとも「ファイルが存在しない」場合はスキップして継続する）。
- 処理対象画像枚数が増えても線形の処理時間で完了すること（大きな画像全体に対する
  重い探索アルゴリズムを避ける）。
- 座標範囲などのパラメータは画像サイズに応じて調整可能な形にすること
  （ハードコードする場合も、定数としてファイル冒頭にまとめること）。

## 8. 受け入れ基準（Acceptance Criteria）

1. 基準画像1枚・対象画像複数枚を入力すると、出力フォルダに対象画像と同数の
   `*_registered.tif` が生成される。
2. 各出力画像は、基準画像に対して縦線の角度・位置・横線の位置が実用上一致している
   （目視、または縦線角度差・col差・row差が閾値以下であることを確認できる）。
3. 対象画像リストに存在しないファイル名が含まれていても、エラーで停止せず、
   スキップメッセージを出して残りの処理を続行する。
4. 標準出力に、基準画像の検出値、各対象画像の補正値、サマリー表が指定フォーマットで
   出力される。
5. 出力画像の輝度値は 0–255 の範囲にクリップされた8bit画像になっている。

## 9. 使用ライブラリ（参考実装）

- 画像入出力: `tifffile`
- 数値計算: `numpy`（線形回帰は `numpy.polyfit`）
- アフィン変換（回転・平行移動）: `opencv-python`（`cv2.getRotationMatrix2D`, `cv2.warpAffine`）

ローカルLLMに実装させる際は、上記に限らず同等機能を持つライブラリ
（例: `Pillow` + `scipy.ndimage`, `scikit-image` 等）への置き換えを許容してよい。

## 10. テストケース例

| No. | 入力 | 期待結果 |
|---|---|---|
| 1 | 基準画像と完全に同一の対象画像 | 回転補正 ≈ 0°、dx ≈ 0、dy ≈ 0 |
| 2 | 基準画像を既知の角度θだけ回転させた画像 | 回転補正 ≈ −θ（符号は実装の角度定義に依存、一貫していること） |
| 3 | 基準画像を既知の(dx0, dy0)だけ平行移動させた画像 | dx ≈ −dx0 相当の補正量（符号規約に注意）、|shift| が既知値に近い |
| 4 | 存在しないファイル名を対象リストに含める | スキップされ、他の画像の処理は正常に完了する |
| 5 | 縦線・横線のコントラストが低い画像 | 検出位置がノイズの影響を受けにくいこと（要検証項目として明記） |

## 11. ローカルLLMへの実装依頼プロンプト（そのまま貼り付け可）

以下は、上記要件定義を元にローカルLLMへ実装を依頼するためのプロンプト例です。
既存実装（`register_images.py`）の内容は含めていないため、LLMが要件のみから
実装できるかどうかの検証に使えます。

```
あなたはPython画像処理のエキスパートです。
以下の要件に従って、基板画像の位置合わせスクリプト（1ファイルのPythonスクリプト）を実装してください。

# 背景
顕微鏡で撮影したグレースケールTIFF画像群を、1枚の基準画像に合わせて
「回転補正」→「平行移動補正」の順に位置合わせする。
補正の手がかりは、画像に写っているほぼ垂直な暗線（縦線）とほぼ水平な暗線（横線）である。

# 入力
- 入力ディレクトリ、基準画像ファイル名、対象画像ファイル名のリストを設定値として持つこと
- 画像はグレースケールTIFF、サイズは概ね2048x2048px

# 処理要件
1. 縦線角度の検出: 指定した列範囲内で、各行の最小輝度列を求め、
   行番号を説明変数・列番号を目的変数として1次線形回帰し、傾きから角度(度)を求める。
2. 縦線col・横線rowの検出: 指定範囲内で列ごと/行ごとの平均輝度が最小となる位置を求める。
3. 基準画像・各対象画像それぞれについて縦線角度・縦線col・横線rowを検出する。
4. 各対象画像に対して:
   a. 回転補正角 = 基準の縦線角度 − 対象の縦線角度 として、画像中心周りに回転する
      （境界は輝度0で埋める、双線形補間）。
   b. 回転後の画像で縦線col・横線rowを再検出する。ただし縦線colの探索範囲は、
      回転前に検出した対象画像の縦線col ± 150px に限定する（画像端でクリップする）。
   c. dx = 基準の縦線col − 回転後の縦線col、dy = 基準の横線row − 回転後の横線row とし、
      その分だけ平行移動する（境界は輝度0で埋める、双線形補間）。
   d. 結果画像を0–255にクリップし8bit化して、`{元ファイル名}_registered.tif` として
      `{入力ディレクトリ}/registered/` に保存する。
5. 対象ファイルが存在しない場合はスキップし、処理を継続する。

# 出力（標準出力ログ）
- 基準画像の検出結果（縦線角度、縦線col、横線row）
- 各対象画像ごとの、縦線角度・回転補正角・dx・dy・移動量(|shift|)・保存先ファイル名
- 全対象画像分のサマリー表（ファイル名、回転角、dx、dy、|ズレ|）

# 制約
- 使用ライブラリは自由（tifffile/opencv/numpy、または Pillow/scikit-image/scipy 等の代替可）
- コメントは最小限、実装ロジックが要件を満たすことを優先すること
```

# sCMOS画像データ 自動バックアップ（I: → G:、一方向）

デジタルカウントプロジェクトのsCMOSカメラ画像を、I:ドライブからG:ドライブへ
一方向で自動バックアップする常駐プロセスの導入手順。

対象PC: remotefdtd（Windows）

> **注意**: このリポジトリを扱っているエージェントは対象のWindows機に
> リモートアクセスできないため、以下の手順はPC上で**手動で実行**してください。

## 前提確認（導入前に必ず実施）

1. `I:\マイドライブ\データ移動` が存在し、アクセス可能か確認する
2. `G:\マイドライブ\1.実験データ_gdrive\5.生データ` が存在し、アクセス可能か確認する
   （存在しない場合は作成してよいか確認してから作成する）
3. 上記2つが実際にこのPC上でドライブとしてマウントされていることを
   エクスプローラー等で確認する

## 導入手順

1. `sync_digitalcount.bat` を `C:\Users\<ユーザー名>\Scripts\` にコピーする
   （`Scripts` フォルダが無ければ作成する）
2. `run_hidden.vbs` をスタートアップフォルダにコピーする
   - `Win+R` → `shell:startup` で開くフォルダが実体パス
   - 通常は `C:\Users\<ユーザー名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`

## 動作要件（このファイル一式で満たしている内容）

- `run_hidden.vbs` は `WScript.Shell.Run` の第2引数を `0`（非表示ウィンドウ）で
  呼び出すため、コンソール窓は表示されない
- `robocopy` の `/MON:1 /MOT:5` により、変更検知後5分間安定してから同期する
  （撮影中ファイルを掴まないため）
- `/MIR` は使用していないため、G:側にしか無いファイルの削除は行われない
  （上書きのみの一方向コピー）
- `run_hidden.vbs` をスタートアップフォルダに置くことで、PC起動時に
  自動的に監視プロセスが起動する

## 導入後の確認手順

1. `run_hidden.vbs` をエクスプローラーからダブルクリックで一度手動実行し、
   タスクマネージャーに `robocopy.exe` プロセスが起動していることを確認する
2. `I:\マイドライブ\データ移動` 配下に適当なテストファイルを置き、
   5〜10分待って `G:\マイドライブ\1.実験データ_gdrive\5.生データ` に
   反映されるか確認する
3. `C:\Users\<ユーザー名>\sync_log.txt` にログが記録されているか確認する
4. すべて確認できたら、テストファイルを削除する（既存データに影響しないよう、
   削除前に必要であれば確認を取る）
